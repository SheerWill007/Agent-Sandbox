# Agent Sandbox website

The public Agent Sandbox landing page is a static Astro site. It introduces the project’s Firecracker/KVM execution model, integration options, and setup requirements, with links to the maintained repository documentation.

## Development

Use Node.js 22.12 or newer.

```sh
npm ci
npm run dev
npm run check
npm test
```

The GitHub Pages build uses the `/Agent-Sandbox/` base path.
